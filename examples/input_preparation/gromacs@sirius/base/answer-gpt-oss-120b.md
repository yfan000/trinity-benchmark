```bash

```

*Explanation:* `gmx grompp` reads the three files above (`md.mdp`, `conf.gro`, `topol.top`) and produces the portable binary run‑input file **prod.tpr**, which is what the MD engine (`gmx mdrun`) actually executes. The `-maxwarn 1` flag is optional and only needed if harmless warnings appear (e.g., missing masses for dummy atoms).
