# Reference answer — gromacs@sirius

Written by Claude and shown to the judge as *one* correct answer, never as the correct one. The judge is told explicitly not to deduct for differing from it where the requirements are met.

````
Required input files for GROMACS running hen egg-white lysozyme solvated in TIP3P water with 0.15 M NaCl, ~34,000 atoms, NPT at 300 K, 2 fs timestep, PME, 5 ns production on Sirius:

**1. md.mdp — run-parameter file**
Must specify:
- integrator = md
- dt = 0.002 (2 fs timestep)
- nsteps = 2500000 (5 ns = 5,000,000 fs / 2 fs)
- pcoupl = C-rescale or Parrinello-Rahman (NPT ensemble)
- tcoupl = V-rescale or Nose-Hoover, ref_t = 300
- coulombtype = PME
- vdwtype = Cut-off (or PME)
- pbc = xyz
- constraints = h-bonds or all-bonds
- gen_vel = no (production run, velocities from prior equilibration)
- continuation = yes
Output frequencies: nstxout-compressed for trajectory, nstenergy, nstlog.

**2. conf.gro — coordinate/velocity file**
A GROMACS-format coordinate file containing all ~34,000 atoms of the lysozyme + TIP3P water + Na+ + Cl- system. Title line, atom count (must match number of coordinate lines written), one line per atom with residue name, atom name, atom number, x y z (nm) and optionally velocities, followed by box vectors. This is obtained from a completed equilibration run (gmx mdrun output) or from structure preparation (gmx solvate, gmx genion). The agent should note this file is produced by prior equilibration and describe its required format and content rather than fabricating 34,000 atom lines.

**3. topol.top — topology file**
Must include:
- [ defaults ] section specifying force-field combination rules
- #include for the chosen protein force field (e.g., CHARMM36 or AMBER ff14SB or OPLS-AA)
- #include for TIP3P water model itp
- #include for ion parameters (Na+, Cl-)
- [ system ] section with a system name
- [ molecules ] section listing molecule counts that exactly match the coordinate file: protein (1), SOL (N_water), NA (N_na), CL (N_cl) — counts must be consistent with ~34,000 atoms and 0.15 M NaCl.

**Optional files that are needed for this workload:**
- `.itp` files: posre.itp (position restraints for protein heavy atoms, generated by gmx genrestr; referenced in topol.top under #ifdef POSRES — not needed for production if continuation=yes, but commonly included)
- Force-field `.itp` files are included via #include from the GROMACS force-field library path; not written by hand.

**TPR build command (not written by hand — binary):**
```
gmx grompp -f md.mdp -c conf.gro -p topol.top -o md.tpr
```
or with an index file if needed:
```
gmx grompp -f md.mdp -c conf.gro -p topol.top -n index.ndx -o md.tpr
```

**Runtime-produced outputs (not written):** md.log, md.edr, md.xtc, md.trr, md.gro, *.cpt

**Key parameter checks:**
- nsteps = 2,500,000 for 5 ns at dt=0.002 ps
- NPT: both pressure and temperature coupling active
- PME electrostatics required (coulombtype = PME)
- Atom count in [ molecules ] must sum to ~34,000 consistent with conf.gro header
- System fits on 1 node of Sirius (max 4 nodes, workq queue, max walltime 86400 s); a 5 ns production of a 34k-atom system on 4× A100 GPUs fits within queue limits
````
